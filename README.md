# Landing Page - Automação e Integração de Sistemas

Esta é a landing page profissional de **Isaac Oliveira**, focada na oferta de serviços de automação de processos, integração de ferramentas e inteligência operacional para empresas que buscam escala e eficiência.

## 🚀 Link do Projeto
O site está publicado em: [https://<SEU_USUARIO>.github.io/<SEU_REPOSITORIO>/](https://<SEU_USUARIO>.github.io/<SEU_REPOSITORIO>/)

## 🛠️ Sobre o Projeto
O projeto foi desenvolvido com uma estética **Tech Premium**, utilizando um design minimalista de "nós e arestas" para comunicar visualmente a especialidade em fluxos de dados e arquitetura de sistemas.

### Principais Soluções Apresentadas:
- **Conexão de Dados:** Integração entre WhatsApp, Google Sheets, CRMs e APIs.
- **Agenda Automática:** Automação de marcação de horários com sincronização em tempo real.
- **Inteligência Operacional:** Dashboards de métricas e triagem inteligente de leads com IA.

## 💻 Tecnologias Utilizadas
- **Frontend:** React.js, TypeScript e Vite.
- **Estilização:** Tailwind CSS (Shadcn/ui).
- **Animações:** Framer Motion.
- **Ícones:** Lucide React.
- **Infraestrutura:** GitHub Actions (CI/CD para deploy automático).

## 🔧 Como rodar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

## 🚢 Deploy (GitHub Pages)
O projeto está configurado para deploy automático via **GitHub Actions**. 

Para que o deploy funcione corretamente:
1. No repositório no GitHub, vá em **Settings > Pages**.
2. Em **Build and deployment > Source**, selecione **GitHub Actions**.
3. Sempre que um `push` for feito para a branch `master`, o GitHub fará o build e publicará a versão mais recente automaticamente.
